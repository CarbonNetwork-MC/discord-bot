Discord bot for Carbon Network's discord servers

## Required Guild Permissions
- View Channels
- Manage Channels
- Manage Roles
- View Audit Log
- Manage Nicknames
- Kick, Approve, and Reject Members
- Ban Members
- Timeout Members
- Send Messages and Create Posts
- Send Messages in Threads and Posts
- Embed Links
- Attach Files
- Add Reactions
- Manage Messages
- Read Message History
- Mute Members
- Deafen Members
- Move Members
